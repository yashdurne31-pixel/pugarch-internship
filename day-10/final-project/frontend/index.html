REST API Endpoints & Developer Integration

Programmatic endpoints for external IoT sensors, regulatory databases, and automated inspection dispatchers.

🚀 Open Swagger Interactive Docs
POST /api/predict
Single Inference

Submits inspection parameters and receives classified risk level, continuous score, confidence, and action items.

curl -X POST "http://localhost:8000/api/predict" \ -H "Content-Type: application/json" \ -d '{ "facility_type": "Restaurant", "temperature_compliance_score": 92.0, "sanitation_protocol_score": 90.0, "water_potability_index": 95.0, "ppe_handwashing_score": 88.0, "pest_control_score": 91.0, "cross_contamination_control": 92.0, "historical_violation_count": 0 }'
GET /api/inspections
Registry Query

Query historical inspections with risk level filters and keyword search.

curl -X GET "http://localhost:8000/api/inspections?risk=High%20Risk&limit=25" \ -H "Accept: application/json"
POST /api/predict/upload-csv
Multipart Batch

Uploads CSV file for batch inference and returns structured results per row.

curl -X POST "http://localhost:8000/api/predict/upload-csv" \ -F "file=@inspections_october.csv"
GET /api/analytics/stats
KPI Dashboard

Aggregated KPIs for real-time compliance monitoring systems.

curl -X GET "http://localhost:8000/api/analytics/stats" \ -H "Accept: application/json"
