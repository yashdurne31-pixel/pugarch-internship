## Day 10 Final Project: AegisHygiene

**Smart Hygiene Risk Prediction System**

AegisHygiene is an educational AI/ML application designed to analyze hygiene inspection information and estimate potential hygiene risks.

### Key Features

* Data preprocessing and cleaning.
* Exploratory Data Analysis (EDA).
* Feature selection.
* Machine learning model training and evaluation.
* Hygiene risk prediction.
* Feature importance visualization.
* Facility and inspection APIs.
* CSV upload functionality.
* Analytics dashboard.
* SQLite database integration.
* Automated testing using Pytest.

### Technology Stack

| Component        | Technologies          |
| ---------------- | --------------------- |
| Programming      | Python, JavaScript    |
| Backend          | FastAPI, Uvicorn      |
| Machine Learning | Scikit-learn          |
| Data Analysis    | Pandas, NumPy         |
| Visualization    | Matplotlib, Seaborn   |
| Database         | SQLite                |
| Frontend         | HTML, CSS, JavaScript |
| Testing          | Pytest                |
| Version Control  | Git, GitHub           |
| Frontend Hosting | Vercel                |
