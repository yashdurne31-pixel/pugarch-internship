# TypeScript Exercises — Day 6

## Run
From this folder, install TypeScript and tsx:
```bash
npm init -y
npm install --save-dev typescript tsx
npx tsx 01-types.ts
npx tsx 02-generics-and-narrowing.ts
```

Topics demonstrated: interfaces, arrays, optional properties, union types, template literals, generics, type narrowing, and reusable functions.
