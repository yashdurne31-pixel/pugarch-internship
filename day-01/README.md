# Day 1 - Programming Fundamentals & Problem Solving

## Project Overview

Day 1 focuses on programming fundamentals, problem-solving techniques, data structures, algorithms, and basic employee management functionality.

## Problem Statement

The objective is to strengthen programming fundamentals by implementing common programming problems and developing a basic Employee Management System.

## Features

### Programming Exercises

- Reverse a string
- Check palindrome
- Find largest number
- Find second largest number
- Character frequency
- Remove duplicates
- Find missing number
- Find duplicate number
- Find first non-repeating character
- Merge sorted arrays
- Find common elements
- Stack implementation
- Queue implementation
- Maximum subarray
- Sorting algorithms

### Employee Management System

- Add employee
- View employee records
- Update employee
- Delete employee
- Search employee

## Technology Stack

- JavaScript
- Node.js
- VS Code
