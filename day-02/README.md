# Day 2 - Python Development

## Project Overview

Day 2 focuses on Python programming fundamentals, data processing, exception handling, file handling, and object-oriented programming concepts.

The practical work includes Python problem-solving exercises, an Employee Management System, and CSV data analysis.

## Problem Statement

The objective is to develop maintainable Python programs that can solve common programming problems, manage employee records, store data using JSON, and analyze CSV data.

## Features

### Python Exercises
- String manipulation
- Palindrome checking
- Number operations
- Character frequency
- Duplicate removal
- Array operations
- Stack and queue implementation
- Maximum subarray
- Sorting algorithms

### Employee Management System
- Add employee
- Update employee
- Delete employee
- Search employee
- List employees
- Filter employees by department
- Sort employees by salary
- Calculate employee statistics
- JSON data storage
- Exception handling

### CSV Analysis
- Record count
- Missing value detection
- Duplicate record detection
- Average salary
- Minimum salary
- Maximum salary
- Department-wise statistics

## Technology Stack

- Python 3
- JSON
- CSV
- Python Standard Library
- VS Code
